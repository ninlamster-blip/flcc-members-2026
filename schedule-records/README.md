# Schedule records

Dated PDF snapshots of a published worker's schedule, kept for the record —
not read by the app. Named `<church-slug>-<year>-<month>.pdf`, e.g.
`abundance-2026-08.pdf` for Abundance Church's August 2026 schedule.

The live data these snapshots capture lives in each church's `data.json`
(see [CHURCHES.md](../CHURCHES.md)); a file here is a point-in-time export,
not the source of truth.
